# Playground QA Checklist

Use this checklist before tagging `v0.3.0-kids`.

## Lesson Flow

- [ ] Lesson 1: Hello, screen
- [ ] Lesson 2: Make it move
- [ ] Lesson 3: Listen for keys
- [ ] Lesson 4: Bouncing
- [ ] Lesson 5: Score and text
- [ ] Lesson 6: Your first game

For each lesson:

- [ ] Lesson text is readable
- [ ] Load starter works
- [ ] Show solution works
- [ ] Run starts the sandbox
- [ ] Done updates the progress dot
- [ ] Next/Prev navigation is correct

## Asset Picker

- [ ] Sprite buttons insert `sprite("name")`
- [ ] Sound buttons insert `play("name")`
- [ ] Asset panel scrolls horizontally without layout shift

## Share Links

- [ ] Share copies a URL
- [ ] Shared URL loads code into editor
- [ ] Non-ASCII source round-trips
- [ ] Long program round-trips

## Runtime

- [ ] Stop tears down the current iframe
- [ ] Re-running creates a clean iframe
- [ ] Keyboard input works after clicking the canvas
- [ ] Compile errors appear above the editor

## Browsers

- [ ] Chrome
- [ ] Safari
- [ ] Firefox
- [ ] Chromebook
