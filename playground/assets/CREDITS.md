# G-Basic Starter Asset Pack Credits

All assets in this directory are released under CC0-1.0 for the G-Basic kids-launch MVP.

The sprites are simple generated pixel-art placeholders created in-repo. The sound effects are generated synthetic WAV tones/noises. They are intentionally lightweight starter assets so every example can run without external downloads.
